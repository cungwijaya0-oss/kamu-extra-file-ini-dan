## Learnings

- IC HTTP outcalls parse response headers with Rust http::HeaderValue::to_str(), which accepts only visible ASCII (32-127). A non-ASCII byte in ANY response header value fails with IC0406 'Failed to parse headers: failed to convert header to a str' BEFORE the transform callback runs, so a header-stripping transform cannot fix it. youtube-transcript.ai returns a non-ASCII em-dash in its x-partnership response header on every successful response, making it uncallable directly from an IC canister; fetching it via https://r.jina.ai/<url> returns the same transcript document with ASCII-only headers.
- r.jina.ai wraps a fetched document with 'Title:'/'URL Source:'/'Markdown Content:' prefix lines and a trailing '---' + 'Generated by ...' footer; a parser must skip the prefix and stop the body at the footer.
- Caffeine Inference: call Config.fromEnv<system>() inside the shared method, model = "router", and ChatApi.createChatCompletion is async* so the helper must be async* and awaited with await*.
- OQL manual entities: a record with a collection field cannot auto-derive; use plans.toEntityManual(...).sample(...).payload(...) with top-level imports of Entity plus one <Type>Value per payload type. Scoped per-user reads need .ownedBy("owner") + .scopedPerUser().
- M0267 'the migration chain requires field X as input; the previous version must provide it' means the pending migration's OldActor does not match the deployed baseline stable signature. Read the check-stable .most file (path under [canisters.<name>.check-stable] in mops.toml) to derive OldActor: an empty actor {} baseline requires OldActor = {} and the migration body must construct the new field (e.g. AccessControl.initState()) rather than reading it from old. mops check --fix's M0223 auto-fix can wrongly add a field to a migration's OldActor; verify OldActor against the .most baseline instead of trusting the auto-fix.
- Motoko: `query` is a reserved keyword and cannot be used as a parameter name; a double-quote character literal must be written '\"'; calling an async* function from a shared mixin method requires await*; Map.toEntityManual<K, V> takes two type arguments.
- Biome requires tabIndex on a non-interactive element carrying role='progressbar'; a useEffect cleanup that calls a component-scope function trips useExhaustiveDependencies; Tailwind's motion-reduce:animate-none disables decorative animate-spin under prefers-reduced-motion.
- ClipPlan.id is a bigint PlanId; pass plan.id.toString() into Link params for the /plans/$planId route and guard route params with /^\d+$/ before BigInt(planId).
- The read tool truncates lines longer than 2000 chars, so a single-line Motoko string literal can appear cut off in a read even when the source is complete; verify with grep/sed before treating it as a real truncation.
- Caffeine Inference: the platform provisions credentials only for the caffeineai-inference-client path (Config.fromEnv<system>() + ChatApi.createChatCompletion); a hand-built _Ic.http_request that reads Config.fromEnv<system>() directly traps with IC0503 'CAFFEINE_INFERENCE_API_KEY is not set' because that env var is not set in the canister.
- ChatApi.createChatCompletion returns a typed response whose choices[0].message.content is ?Text, so the assistant text can be read directly without any serde-core JSON.toCandid tree walk; guard choices.size() == 0 first.
- The serde-core JSON parser (JSON.toCandid -> JSON.parse -> parser-combinators many/valueParser) is non-tail recursive and overflows the wasm stack (IC0502) on large or deeply nested JSON; avoid it for large model responses and use iterative raw-text extraction instead.
- Motoko's `with` expression for cycle-attached calls requires a named field binding: `await (with cycles = config.cycles) _Ic.http_request(...)`, not `(with config.cycles)`.
- Motoko array literals have no spread operator; combine arrays with Array.concat (or the .concat(...) method form).
